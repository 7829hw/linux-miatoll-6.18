# audio13 실기기 결과 — 이어폰 3버튼 짧게 누름 15/15 정상

2026-10-27 KST. audio12 + 측정 전용 버튼 구간(75/150/237/400/450/500/575/650 mV)으로 시험했다.
레지스터 BTN0–4 = 0x18/0x30/0x48/0x80/0x90이다. vth는 12.5 mV 단위로 75/150/225/400/450 mV에 해당한다.
누름마다 press/release IRQ, 래치된 `ANA_MBHC_RESULT_3` 하위 3비트, `event4` 입력 이벤트를 함께 기록했다.

| 버튼 | 짧게 누름 | 입력 이벤트 | 래치 결과 |
| --- | --- | --- | --- |
| 볼륨 − | 5 | KEY_VOLUMEDOWN 5/5 | 3 (225–400 mV) |
| 볼륨 + | 5 | KEY_VOLUMEUP 5/5 | 2 (150–225 mV) |
| 가운데 | 5 | KEY_MEDIA 5/5 | 0 (< 75 mV) |

- press/release IRQ는 누름마다 1회씩, 모두 15/15였다.
- 볼륨 −는 BTN_3 상한을 400 mV로 낮춰도 BTN_3 안에 있었다. 따라서 audio12 임계값(BTN_3 225–500 mV)의 경계 문제가 아니다.
  - audio12에서 이벤트가 없던 2회는 사용자가 캡처 시간 밖에 누른 것으로 판단한다. 사용자도 제때 못 눌렀다고 했다.
- 길게 누름(audio12)은 3버튼 모두 키 down/up이 정상이었다.
- 결론: 최종 후보는 audio12 임계값을 그대로 쓴다. audio13 구간은 측정용이다.
