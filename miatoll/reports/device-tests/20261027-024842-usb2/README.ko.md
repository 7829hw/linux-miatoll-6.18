# usb2 첫 시도 — fastboot 전송 정지(부팅 안 됨)

2026-10-27 KST. `reboot bootloader` 후 `fastboot boot`가 120초 동안 응답 없이 멈췄다.
이어진 `getvar product`도 20초 안에 응답하지 않았다. 폰은 Fastboot 화면 그대로였고 쓰기 명령은 없다.
규칙에 따라 재전송하지 않고 중단했다. 사용자가 전원+볼륨 아래로 Fastboot를 새로 시작한 뒤,
승인을 받아 1회 재시도했고 성공했다(`20261027-025327-usb2-retry`).
이전 회차들은 같은 128 MiB 전송을 약 3초에 마쳤다. usbipd-win(USB/IP) 전송 정지로 추정하지만 확인하지 않았다.
당시 실행기는 시간 초과 예외를 기록하지 못해 해당 명령 줄을 사후에 추가했다. 이후 실행기는 시간 초과를 로그에 남기고 멈춘다.
