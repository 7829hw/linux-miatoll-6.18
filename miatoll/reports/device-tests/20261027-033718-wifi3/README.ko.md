# wifi3 실기기 결과 — WCN3990 PMF peer 비트 보완 후 지연 개선

2026-10-27 KST. 브랜치 `miatoll/6.18-wifi3`, 커널 `6.18.58-miatoll-wifi3+`.
wifi2와의 차이는 이름과 ath10k 변경 하나(`e1cb32d9`, 공개 ath-next 제안 1/3의 로컬 backport)다.
RAMdisk에는 `/tmp` 수정이 들어갔다. `fastboot boot` 1회, 같은 AP(5500 MHz)에서 시험했다.
판정: **WPA3 연결이 스크립트 끝까지 완료됐고, 공유기 지연이 크게 줄었다.**
비밀번호는 사용자가 USB 키보드로 폰 화면에 입력했고 시험 뒤 RAM에서 지웠다.

## 해석과 한계

- 펌웨어 peer 명령에 PMF 비트가 들어가자 지연이 약 1/10로 줄고, 수신 속도가 6 Mbit/s에서 VHT 650 Mbit/s로 바뀌었다.
  보호된 관리·Block Ack 처리가 정상화된 결과로 보이지만, 무선 프레임을 직접 캡처해 확인하지는 않았다.
- wifi2 기준값은 5회 표본이고 절전 상태를 기록하지 않았다(기본 on으로 추정). 두 회차는 서로 다른 부팅이다.
  절전 off는 RAM 상태에서만 바꾼 진단 설정이며 지연의 나머지 대부분이 절전 대기임을 보여 준다.
- 제안 패치의 upstream 병합 여부는 확인하지 못했다. 처리량, 2.4 GHz, 장시간, 재연결, 공장 MAC은 미검증이다.
