# audio12 유휴 전력 — 새 부팅, TX 유지 적용

2026-10-27 KST. 최종 후보 audio12를 새로 부팅해 150 s 동안 안정화한 뒤 audio14와 같은 방법으로 측정했다. TX active, RX suspended 상태였다.
- 1회차: 무효. 샘플러가 방전을 5분 안에 감지하지 못했다(USB가 그 시간 안에 뽑히지 않음). QG 자체는 정상이었다(연결 중 +120 mA 충전으로 확인).
- 2회차: 평균 −38.8 mA @ 4.433 V. 30 s 블록은 −42.9 −35.9 −37.1 −41.8 −35.1 −40.0.

## 결론 (audio13·audio14와 함께)
- TX 유지 없음 −37.7 mA, 같은 부팅에서 TX 강제 active −37.2 mA, audio12 TX 유지 −38.8 mA.
- 블록 간 변동이 약 ±4 mA이므로, TX SoundWire 유지 비용은 이 측정의 분해능(약 1–2 mA, 수 mW) 안이다.
- audio13 세션의 −94.5 mA는 같은 유지 상태에서 나온 값이지만 재현되지 않았다. 20분 넘게 오디오 시험을 반복한 뒤 남은 다른 상태가 원인으로 보인다(원인 미확인).
- 미측정: system suspend, 화면 켠 상태, Wi-Fi·BT 연결 상태.
